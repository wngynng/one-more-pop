# One More Pop

A small, three-level chain-reaction game. Tap golden kernels and pop the whole pot in three taps or fewer.

## Play

https://wngynng.github.io/one-more-pop/

No download, account, or timer. Mouse, touch, and keyboard supported. Chinese / English toggle, undo, hints, pause, and browser-local progress.

## Run locally

Open `index.html` in a modern browser. No installation or external assets required.

## Deployment

GitHub Pages serves the root of `main`. The `.nojekyll` file keeps this a plain static site.
